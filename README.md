# PET 全能冒险岛

剑桥 PET（B1 Preliminary）备考小游戏，纯前端单文件、零依赖、无需联网。手机、平板、电脑都能直接打开。

## 四个入口

| 入口 | 玩法 |
|---|---|
| 📅 每日打卡 | 设定每天目标题数，按比例抽 词汇 + 语法 + 口语 题，答完算打卡，记录连续天数 |
| 🚀 自由闯关 | 词汇森林 / 语法山 / 口语村 三个关卡，按正确率给 0–3 颗星 |
| 🏘️ 口语村打卡 | 24 周亲子口语计划，每天走 功能词块 → 跟读 → 句型替换 → 限时独白 → 真题题型 五步 |
| 🍉 切水果背单词 | 水果横飞，切掉与题目匹配的那个；3 条命、连击加分，内置错词本 |

## 切水果背单词

- **两种方向**：中→英（给中文切英文）／英→中（给英文切中文）
- **三种难度**：Easy / Normal / Hard，控制水果上升速度与同时在场数量
- **可选题库范围**：全部 / 名词 / 动词 / 形容词（来自 PET 完整词库，自动按词性归类）
- 切对加分、连击越高分越高，切错或漏掉扣 ❤️，3 条命耗完结算
- 结束页有**错词本**，把切错/漏掉的词列出来
- 顶部工具条可切换音效与朗读开关；键盘 `Esc` 退出，`空格` 暂停
- 朗读复用冒险岛同一套 TTS（百度主源），所以在微信里也能正常发音

## 口语村（24 周口语打卡）

- **24 周计划**：从「基础夯实期」到「冲刺模拟期」，每周 7 天，共 168 天
- **每天 5 个任务**（约 12–15 分钟）
  1. **功能词块**：4 个整块记忆的功能句（开场延展 / 征询协作 / 观点理由 / 救场描述），每个可点 🔊
  2. **跟读（4/3/2 流利度训练）**：3 句递进 + 1 句拓展句，慢读 → 跟读 → 计时快读
  3. **句型替换**：给 1 个句型框架 + 3 组替换词，孩子自己把 3 句说出来（举一反三，不是背句子）
  4. **限时独白**：话题 + 追问 + 答题模板，用页面里的 ⏱ 计时器撑满 30 秒（复习日 60 秒）
  5. **真题题型**：当周对应的剑桥 PET 口试题型卡（考官问句 + 参考答案 + 功能句）+ 1 道口语选择题，答对得 ⭐
- **每周第 6、7 天是间隔复习日**（🔁）：不是重复当天内容，而是把 Day 1–3、Day 4–5 + 上周 Day 1 的词块和句型**重新调出来**说一遍
- 进度与填空内容存在浏览器本地（`localStorage`），关掉网页也不会丢

## 口语村内容对齐的考试标准

内容按剑桥 **B1 Preliminary（PET）口语** 四个部分轮换编排，24 周刚好走两轮：

| 周次 | 题型 | 练什么 |
|---|---|---|
| 1–2 / 9–10 | Part 1 面试 | 关于自己的日常、喜好、经历，把回答说长 |
| 3–4 / 11–12 | Part 2 独白 | 看一张照片描述人、地点、动作、感受，撑满 1 分钟 |
| 5–6 / 13–14 | Part 3 协作 | 和同伴商量情境、提建议、征询意见、做决定 |
| 7–8 / 15–16 | Part 4 讨论 | 给观点 + 理由，礼貌赞同或反对 |
| 17–18 | Part 1 & 4 | 面试式 + 观点式混合 |
| 19–20 | Part 2 & 3 | 描述 + 协作混合 |
| 21–24 | Full mock | 完整四部分模拟，附考场救场语言与心态 |

每天的第 2、4 步对应 **Pronunciation / Discourse Management**，第 1、3 步对应 **Grammar & Vocabulary**，第 5 步对应 **Interactive Communication**——正好覆盖考官打分表上的四个维度。

## 内容说明

- 词汇：PET 核心词库 + 中文释义，抽词出题
- 语法：时态 / 语态 / 从句 / 比较级 / 情态动词 等 36 道
- 口语：场景表达选择题，覆盖打招呼、点餐、问路、看病、购物等
- 口语村：24 周 × 每天 1 个话题，句式统一为三阶递进；120 个学习日各配 4 个功能词块、1 个替换框架、1 句拓展句、1 条发音贴士，另有 24 张真题题型卡与 72 道主题口语选择题

## 技术说明

- 单文件 `index.html`，无构建、无依赖
- 音效由 Web Audio 生成，无外部音频文件
- **发音（TTS）**：主源用百度翻译 TTS（对任意句子都有效），有道词典 TTS 兜底，
  最后才回退浏览器 SpeechSynthesis。
  - 页面设了 `<meta name="referrer" content="no-referrer">`——百度该接口带外部 Referer 会返回空内容（静音）
  - 喇叭按钮有三态：⏳ 加载中 / 🔊 播放（高亮）/ 🔇 读不出来
  - 每次点击先停掉上一句再播新的，不做排队（排队会导致"点 A 响 B"的串音）
