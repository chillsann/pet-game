# PET 全能冒险岛

剑桥 PET（B1 Preliminary）备考小游戏，纯前端单文件、零依赖、无需联网。手机、平板、电脑都能直接打开。

## 四个入口

| 入口 | 玩法 |
|---|---|
| 📅 每日打卡 | 设定每天目标题数，按比例抽 词汇 + 语法 + 口语 题，答完算打卡，记录连续天数。**答题不限时**，想好了再选，答完自己点「下一题」 |
| 🚀 自由闯关 | 词汇森林 / 语法山 / 口语村 三个关卡，按正确率给 0–3 颗星 |
| 🏘️ 口语村打卡 | 24 周亲子口语计划，每天走 功能词块 → 跟读 → 句型替换 → 限时独白 → 真题题型 五步 |
| 🍉 切水果背单词 | **闯关模式**：3 座岛 × 56 关，每关先看 50 个词再切；另有自由练习模式 |

## 切水果背单词

### 闯关模式（主玩法）

把 2706 个 PET 词按词性分成 **3 座岛**，每座岛内**先短词后长词**排序，切成 50 词一关，共 **56 关**：

| 岛 | 词数 | 关卡 | 起手是什么词 |
|---|---|---|---|
| 🗻 名词岛 | 1631 | 33 关 | act / age / art / bag / bed / box |
| 🌋 动词岛 | 714 | 15 关 | 短动词起手 |
| 🏔️ 形容词岛 | 361 | 8 关 | 短形容词起手 |

> 词库本身是按字母序排的，直接切关会让第 1 关变成 accommodation / advertisement 这类长抽象词。
> 所以岛内额外按**词长升序**排，保证第一关就是孩子认得的三四个字母的词。

每关走三步：

1. **词汇快速记忆**（**不限时**，按自己的节奏来）—— 50 个词分 **5 页 × 10 张词卡**，大字号英中对照，
   点卡片就能听发音。最后还多一页「🔁 复习」，混入 5 个前面关学过的旧词（间隔重复）。
   顶部有「遮住中文自测」开关，看完可以盖住中文回忆一遍。不想看可以随时跳过。
2. **开始切水果** —— 从本关 50 词池里抽题，**固定 15 题**，❤️ 3 颗命。
   - 前 8 题「看英文认中文」，后 7 题「看中文想英文」，由易到难
   - 关内难度爬坡：第 1 题 2 个水果，最后一题 4 个
   - **答错先「再试一次」**：第一次切错不扣命，同一题重新飞一遍让孩子自己纠正；第二次再错才扣 ❤️
   - **手滑漏掉不扣命**：正确水果掉下去只算失误、进错词本，不扣命（手机上手指一滑掉半颗心太冤）
3. **结算与解锁** —— 按正确率给星：≥90% ⭐⭐⭐ / ≥75% ⭐⭐ / ≥60% ⭐。
   因命耗尽提前结束的最高 1 星。**拿到 1 星即解锁下一关**，没达标可无限重玩、不惩罚。
   结算页有本关错词（点一下听发音），还有「翻看本关 50 词」。

其他：

- **全程不限时**：每日打卡 / 自由闯关 / 切水果都没有倒计时催促，孩子可以慢慢认、慢慢想，答完自己点「下一题」
- 关卡地图显示每关星级、锁状态和岛内进度；已通关与 ⭐ 总数永久保存在 `localStorage`（键 `fs_progress`）
- 结算后错词会累积到 `fs_progress.wrongWords`，家长可读出来针对性抽查
- 可以手动重置进度：控制台执行 `FruitSlicer.resetProgress()`

### 自由练习模式

从切水果首页点「🎠 开始自由练习」进入原来的无限模式：

- **两种方向**：中→英（给中文切英文）／英→中（给英文切中文）／混合出题
- **三种难度**：慢速 / 标准 / 挑战，控制水果上升速度与同时在场数量
- **可选题库范围**：全部 / 名词 / 动词 / 形容词
- 切对加分、连击越高分越高，切错或漏掉扣 ❤️，3 条命耗完结算
- 结束页有**错词本**，把切错/漏掉的词列出来
- 顶部工具条可切换音效与朗读开关、返回关卡地图；键盘 `Esc` 退出，`空格` 暂停，`Enter` 开始/重开
- 朗读复用冒险岛同一套 TTS（百度主源），所以在微信里也能正常发音

## 口语村（24 周口语打卡）

- **24 周计划**：从「基础夯实期」到「冲刺模拟期」，每周 7 天，共 168 天
- **每天 5 个任务**（约 12–15 分钟）
  1. **功能词块**：4 个整块记忆的功能句（开场延展 / 征询协作 / 观点理由 / 救场描述），每个可点 🔊
  2. **跟读（4/3/2 流利度训练）**：3 句递进 + 1 句拓展句，慢读 → 跟读 → 计时快读
  3. **句型替换**：给 1 个句型框架 + 3 组替换词，孩子自己把 3 句说出来（举一反三，不是背句子）
  4. **限时独白**：话题 + 追问 + 答题模板，用页面里的 ⏱ 计时器撑满 30 秒（复习日 60 秒）
  5. **真题题型**：当周对应的剑桥 PET 口试题型卡（考官问句 + 参考答案 + 功能句）+ 1 道口语选择题，答对得 ⭐
- **每周第 6、7 天是间隔复习日**（🔁）：不是重复当天内容，而是把 Day 1–3、Day 4–5 + 上周 Day 1 的词块和句型**重新调出来**说一遍
- 进度与填空内容存在浏览器本地（`localStorage`），关掉网页也不会丢

## 口语村内容对齐的考试标准

内容按剑桥 **B1 Preliminary（PET）口语** 四个部分轮换编排，24 周刚好走两轮：

| 周次 | 题型 | 练什么 |
|---|---|---|
| 1–2 / 9–10 | Part 1 面试 | 关于自己的日常、喜好、经历，把回答说长 |
| 3–4 / 11–12 | Part 2 独白 | 看一张照片描述人、地点、动作、感受，撑满 1 分钟 |
| 5–6 / 13–14 | Part 3 协作 | 和同伴商量情境、提建议、征询意见、做决定 |
| 7–8 / 15–16 | Part 4 讨论 | 给观点 + 理由，礼貌赞同或反对 |
| 17–18 | Part 1 & 4 | 面试式 + 观点式混合 |
| 19–20 | Part 2 & 3 | 描述 + 协作混合 |
| 21–24 | Full mock | 完整四部分模拟，附考场救场语言与心态 |

每天的第 2、4 步对应 **Pronunciation / Discourse Management**，第 1、3 步对应 **Grammar & Vocabulary**，第 5 步对应 **Interactive Communication**——正好覆盖考官打分表上的四个维度。

## 内容说明

- 词汇：PET 核心词库 + 中文释义，抽词出题
- 语法：时态 / 语态 / 从句 / 比较级 / 情态动词 等 36 道
- 口语：场景表达选择题，覆盖打招呼、点餐、问路、看病、购物等

## 技术说明

- 单文件 `index.html`，无构建、无依赖
- 音效由 Web Audio 生成，无外部音频文件
- **发音（TTS）**：主源用百度翻译 TTS（对任意句子都有效），有道词典 TTS 兜底，
  最后才回退浏览器 SpeechSynthesis。
  - 页面设了 `<meta name="referrer" content="no-referrer">`——百度该接口带外部 Referer 会返回空内容（静音）
  - 喇叭按钮有三态：⏳ 加载中 / 🔊 播放（高亮）/ 🔇 读不出来
  - 每次点击先停掉上一句再播新的，不做排队（排队会导致"点 A 响 B"的串音）
- **性能**（2026-09 针对"手机上很卡"做过一轮优化，同一场景实测 **≈19fps → ≈60fps**）：
  - 渲染分辨率上限压到 1.5×DPR（手机上按 3× 渲染等于多画一倍多像素，肉眼几乎看不出差别）
  - 水果与切开的碎片改成**离屏位图缓存**，不再每帧重建径向渐变、描边文字（这两项原本每帧各上百次）
  - 首页 / 记忆页 / 关卡地图等静态画面**停止 canvas 重绘**，页面切到后台时也停
  - 去掉导致移动端掉帧的全屏毛玻璃 `backdrop-filter`，渐变背景改放到固定层（滚动不再反复重绘）
  - 短了切割拖尾寿命、减少爆裂粒子数量
- **触屏适配**：`:hover` 只在真正支持悬停的设备上生效。手机浏览器会把上一次的触摸点一直"粘"在 hover 上，
  导致刚进入题目时某个选项自带紫色高亮，孩子会误以为那个已经被选中——现在触屏下不再出现。
